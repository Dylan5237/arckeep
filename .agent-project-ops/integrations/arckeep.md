# 可选接入：Arckeep

本项目选择了 Arckeep；这份说明只定义接入边界，不会自动安装或连接服务。

1. 先由项目负责人确认可用的 Arckeep 环境、访问权限和允许同步的项目范围。没有现成接口或权限时，保持未连接并在总控台记录缺口。
2. APO 的权威状态仍是 GitHub Issue、PR 和提交。Arckeep 只能引用这些状态与证据，不能替拍板人批准、验收或改变冻结合同。
3. 接入前通过项目任务说明拟读写的数据、实际接口与失败处理。涉及账号、权限或数据外传时，按大改动清单取得该项目的批准。
4. 不把令牌、私人会话或未脱敏业务数据写入规则文件、GitHub 或同步载荷。失败时记录实际结果，不把请求发送成功当作远端记录已确认。

接入状态由项目总控台维护：未连接 / 已核实只读 / 已核实指定写入。只有实际核实过的能力才能登记。
